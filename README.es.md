# Este repositorio

Este repositorio guarda la página pública de la organización ADRenaline.

La página que la gente ve en [github.com/ADRenaline-Suite](https://github.com/ADRenaline-Suite) es [profile/README.md](profile/README.md). La página en español es [profile/README.es.md](profile/README.es.md). El wordmark, el hero y las marcas de idioma viven en esa misma carpeta.

## Cuando un plugin se publica en GitHub

Añade una línea a las dos páginas del perfil, en el mismo cambio. La línea enlaza el repositorio y dice, en lenguaje llano, qué puede pedirle una persona a ese plugin. Déjala en el grupo del oficio al que pertenece. Actualiza la cuenta en el párrafo de apertura de las dos páginas.

El nombre del repositorio dice qué es.

| Empieza por | Es |
| --- | --- |
| `plugin-` | Un plugin de agente. |
| `template-` | Un proyecto para copiar y arrancar. |
| `base-` | Un proyecto completo de la suite. |

Un plugin que solo tiene `TODO.md` se queda fuera del perfil.

## Reputación

GitHub muestra [profile/README.md](profile/README.md) en el resumen de la organización. [profile/README.es.md](profile/README.es.md) está a un enlace.

La frase junto al nombre, en buscadores y en las vistas previas de un enlace, es la descripción de la organización. No es este README. Cabe en 160 caracteres y dice lo mismo que el primer párrafo de la página pública: plugins de agente para Cursor y Claude Code, un oficio escribe el archivo.

La imagen de esas vistas previas es el avatar de la organización. Sube [profile/mark.png](profile/mark.png).

Fija seis repositorios de oficio en el resumen. Este repositorio es la página. No necesita un pin.
