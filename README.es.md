# Este repositorio

Este repositorio guarda la página pública de la organización ADRenaline.

La página que la gente ve en [github.com/ADRenaline-Suite](https://github.com/ADRenaline-Suite) es [profile/README.md](profile/README.md). La página en español es [profile/README.es.md](profile/README.es.md). El wordmark y las marcas de idioma viven en esa misma carpeta.

## Cuando un plugin se publica en GitHub

Añade una línea a las dos páginas del perfil, en el mismo cambio. La línea enlaza el repositorio y dice, en lenguaje llano, qué puede pedirle una persona a ese plugin. Déjala en el grupo del oficio al que pertenece.

El nombre del repositorio dice qué es.

| Empieza por | Es |
| --- | --- |
| `plugin-` | Un plugin de agente. |
| `template-` | Un proyecto para copiar y arrancar. |
| `base-` | Un proyecto completo de la suite. |

Un plugin que solo tiene `TODO.md` se queda fuera del perfil.
