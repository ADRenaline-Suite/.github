# This repository

This repository holds the public page of the ADRenaline organization.

The page people see on [github.com/ADRenaline-Suite](https://github.com/ADRenaline-Suite) is [profile/README.md](profile/README.md). The Spanish page is [profile/README.es.md](profile/README.es.md). The wordmark and the language marks live in that same folder.

## When a plugin is published on GitHub

Add one line to both profile pages, in the same change. The line links the repository and says, in plain language, what a person can ask that plugin to do. Keep the line in the group where that craft belongs.

A repository name says what it is.

| Starts with | It is |
| --- | --- |
| `plugin-` | An agent plugin. |
| `template-` | A project to copy and start from. |
| `base-` | A complete project of the suite. |

A plugin that only has `TODO.md` stays off the profile.
