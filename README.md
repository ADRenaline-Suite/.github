# This repository

This repository holds the public page of the ADRenaline organization.

The page people see on [github.com/ADRenaline-Suite](https://github.com/ADRenaline-Suite) is [profile/README.md](profile/README.md). The Spanish page is [profile/README.es.md](profile/README.es.md). The wordmark, the hero, and the language marks live in that same folder.

## When a plugin is published on GitHub

Add one line to both profile pages, in the same change. The line links the repository and says, in plain language, what a person can ask that plugin to do. Keep the line in the group where that craft belongs. Update the count in the opening paragraph of both pages.

A repository name says what it is.

| Starts with | It is |
| --- | --- |
| `plugin-` | An agent plugin. |
| `template-` | A project to copy and start from. |
| `base-` | A complete project of the suite. |

A plugin that only has `TODO.md` stays off the profile.

## Reputation

GitHub shows [profile/README.md](profile/README.md) on the organization overview. [profile/README.es.md](profile/README.es.md) is one link away.

The sentence next to the name, in search results and in link previews, is the organization description. It is not this README. It is at most 160 characters and it should say the same thing as the first paragraph of the public page: agent plugins for Cursor and Claude Code, one craft writes the file.

The picture in those previews is the organization avatar. Upload [profile/mark.png](profile/mark.png).

Pin six craft repositories on the overview. This repository is the page itself. It does not need a pin.
